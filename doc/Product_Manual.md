## 1. 产品简介

**LibraryCoverStudio** 是您的私人媒体库美化专家。

它专为 Jellyfin/Emby 玩家打造，解决了传统刮削封面风格杂乱、缺乏系列感的痛点。通过我们全新的 **Premium UI** 可视化设计器，您可以像使用专业修图软件一样设计模板，然后让自动化引擎在后台默默为您的数千部影片穿上整齐划一的“新衣”。

---

## 2. 快速开始 (Quick Start)

只需三步，从杂乱到整洁：

1.  **连接 (Connect)**: 在 [媒体源] 页面输入您的服务器地址和 API Key，打通数据链路。
2.  **设计 (Design)**: 进入 [模板库]，拖拽图片、文本和 `{{title}}` 变量，创造您的专属风格。
3.  **调度 (Schedule)**: 设定 [定时任务]，绑定模板与媒体库，系统将自动巡检并更新封面。

## 3. 核心模块指南

### 3.1 媒体源连接 (Media Sources)

这是管理数据的入口。

- **添加服务器**:
  - **地址**: 输入完整 URL，如 `http://192.168.1.10:8096`。
  - **API Key 获取方式**:
    - _Jellyfin_: 控制台 > API 密钥 > ➕ 新建。
    - _Emby_: 设置 > 高级 > API 密钥 > ➕ 新建。
- **浏览库**:
  - 连接成功后，展开服务器即可预览所有媒体库（电影、剧集等）。系统会缓存库结构以加快浏览速度。

### 3.2 创意设计器 (Creative Designer)

全新的 React 19 引擎驱动，带来丝般顺滑的设计体验。

#### 🎨 界面分布

- **画布区 (Center)**: 所见即所得的创作舞台。支持鼠标滚轮缩放、右键/按住空格拖拽画布。
- **工具栏 (Left)**:
  - 📌 **海报容器 (Poster)**: 核心组件。放置后，系统会自动将影片原海报填入此区域。
  - 📝 **文本 (Text)**: 支持多行文本、字体选择、阴影与描边。
  - 🖼️ **图片/形状**: 导入 Logo、角标、**多边形 (Polygon)** 或背景蒙版。
- **属性面板 (Right)**: 精细调节选中对象的坐标、尺寸、透明度与图层顺序。

#### 💡 动态变量

让一个模板适配所有电影的关键。在文本框输入以下变量：

- `{{title}}`: 电影/剧集标题
- `{{year}}`: 上映年份
- `{{rating}}`: 评分 (e.g. 9.1)
- `{{genres}}`: 类型 (e.g. 科幻 / 动作)
- `{{primary_title}}`: 主标题
- `{{secondary_title}}`: 副标题 (如果有)

### 3.3 自动化任务 (Automation)

- **策略配置**:
  - **模板映射**: 为不同的库指定不同的模板。例如：给 "4K原盘" 库套用带有 "4K UHD" 角标的模板。
  - **覆写保护**: 建议开启 `Skip if Locked` (跳过已锁定的项目)，防止覆盖您手动精心挑选的封面。
- **执行计划**:
  - 支持 Cron 表达式（如 `0 4 * * *` 每天凌晨4点）。
  - 支持并发布局，即时处理大量海报生成任务。

## 4. 进阶玩法

### 🌟 技巧：制作“系列合集”风格

1.  **统一页眉**: 在模板顶部添加一个深色矩形条作为背景。
2.  **系列Logo**: 导入您的系列 Logo 图片（如 "Marvel Universe"）放在页眉处。
3.  **动态标题**: 在下方放置 `{{title}}`。
4.  **应用**: 将此模板应用到您的 Marvel 收藏集，瞬间获得统一的收藏套装感。

### 🎨 技巧：高级背景处理

使用 **Container Mode**：

- **Cover 模式**: 图片填满容器，适合做全屏背景。
- **Contain 模式**: 图片完整显示，适合显示原海报的核心内容。

## 5. 设置指南 (Settings)

在这里个性化您的 LibraryCoverStudio 体验。

### 🎭 外观设置 (Appearance)
- **显示模式**: 切换 浅色/深色/跟随系统 主题。
- **品牌色彩**: 选择 Jellyfin 紫色风格或 Emby 绿色风格。

### 🔤 字体管理 (Custom Fonts)
- **上传字体**: 支持上传 `.ttf`, `.otf`, `.woff` 格式的字体文件。
- **使用字体**: 上传后，在设计器的文本属性面板中即可选择您添加的自定义字体。

### ⚡ 渲染设置 (Rendering)
- **输出格式**: 选择生成海报的格式 (PNG/JPEG/WebP)。
- **输出质量**: 设置图片压缩质量 (1-100)。
- **并发数量**: 设置后台同时处理的任务数，建议根据服务器性能调整 (默认为 3)。

### 💾 数据管理
- **导出数据**:在此处备份您的模板和配置。
- **清理缓存**: 释放临时文件占用的空间。

## 6. 故障排查 (Troubleshooting)

**Q: 为什么海报生成了，但文字是方框 (□□)？**

> **A**: 这是因为系统缺少显示该文字所需的字体。
> **解决方法**: 请进入 [设置] > [自定义字体] 页面，上传包含所需字符的字体文件（如“思源黑体”等），然后在设计器中选中该文本框并应用新字体。

**Q: 连接 Jellyfin 提示 Refused？**

> **A**: 请检查网络连通性。如果都在 Docker 内，请使用容器名互联；如果不在同一网络，请使用局域网 IP。避免使用 `localhost`。

**Q: 生成速度慢？**

> **A**: 图片合成是 CPU 密集型任务。在 NAS 等低功耗设备上，处理一张海报可能需要 1-2 秒。系统会自动限制并发以保证稳定性，您可以在 [设置] 中调整并发数量。
