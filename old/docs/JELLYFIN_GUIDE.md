# 🎬 媒体服务器集成指南 (Jellyfin/Emby)

本文档介绍如何将 LibraryCoverStudio 与您的媒体服务器（如 Jellyfin 或 Emby）集成，以实现海报自动更新。

## 🔗 连接配置

### 1. 获取 API 密钥
- **Jellyfin**: 控制台 -> 控制面板 -> API 密钥 -> 添加。
- **Emby**: 设置 -> API 密钥 -> 生成。

### 2. 在系统中添加媒体源
1. 进入“媒体源”页面。
2. 点击“添加媒体源”。
3. 填入服务器地址（如 `http://192.168.1.100:8096`）及 API 密钥。
4. 点击“测试连接”确认状态。

## 🤖 自动化工作流

### 定时任务设置
您可以为不同的媒体库配置不同的海报模板：
- **媒体库-模板映射**: 例如，电影库使用“电影简约模板”，剧集库使用“剧集详细模板”。
- **Cron 表达式**: 支持灵活的调度（如 `0 2 * * *` 表示每天凌晨 2 点运行）。
- **执行逻辑**: 系统会自动抓取媒体库中最近添加或评分较高的媒体，应用模板生成海报，并自动上传回媒体服务器。

## 🛠️ API 细节

### 受支持的端点
系统通过 `MediaServerService` 抽象层与服务器通信：
- **获取库**: `GET /api/media-sources/:id/libraries`
- **海报上传**: 自动通过服务器 API 替换 `Primary` 图像。
- **过滤支持**: 支持按日期、类型及特定库进行过滤。

## 📋 故障排除

1. **连接失败**: 
   - 检查服务器是否开启了外网访问或在同一局域网。
   - 确认 API 密钥具有足够的权限。
2. **海报未更新**: 
   - 检查任务日志（Logs 页面）。
   - 确认媒体项是否有原始海报。
3. **Jellyfin 特殊说明**: 
   - 建议在 Jellyfin 设置中关闭“禁止修改海报”相关选项。
