# 🎨 海报设计器使用指南

LibraryCoverStudio 提供了一个强大的可视化海报设计器，基于 Fabric.js 构建。

## 💎 核心功能

- **图层操作**: 支持文字、图片、形状的自由移动、缩放和层级调整。
- **占位符系统**: 支持海报、媒体库属性、媒体信息的动态占位符。
- **多种形状**: 矩形、正方形、圆形、三角形、五角星等，可用海报图片填充。
- **导出与备份**: 模板可以保存至服务器并随时通过 JSON 格式导出。

## 🔖 占位符系统

### 海报占位符

用于图片元素，生成海报时会自动替换为媒体库的封面。

| 占位符 | 说明 |
|-------|------|
| `{{poster1}}` - `{{poster10}}` | 自动填充媒体库中前 N 个媒体的封面 |

### 媒体库属性占位符

用于文字元素，可配置不同媒体库的名称显示。

| 占位符 | 说明 | 示例 |
|-------|------|------|
| `{{library_name}}` | 媒体库名称 | "Anime" |
| `{{library_ch_name}}` | 中文名称 | "动漫" |
| `{{library_eng_name}}` | 英文名称 | "ANIME" |

### 媒体信息占位符

用于文字元素，替换为具体媒体的信息。

| 占位符 | 说明 |
|-------|------|
| `{{title}}` | 媒体标题 |
| `{{year}}` | 发行年份 |
| `{{rating}}` | 评分 |
| `{{genres}}` | 类型/标签 |
| `{{overview}}` | 简介 |

## 🚀 技巧与快速上手

### 1. 创建媒体库封面模板

1. 添加背景（纯色/渐变/随机渐变）
2. 添加海报元素，选择形状和默认图片
3. 在属性面板设置海报元素的占位符为 `poster1`、`poster2`...
4. 添加文字元素，设置占位符为 `{{library_ch_name}}`
5. 保存模板

### 2. 配置媒体库占位符映射

在定时任务中配置媒体库的属性映射：

```json
{
  "library_name": "Anime",
  "library_ch_name": "动漫",
  "library_eng_name": "ANIME",
  "poster_sort": "DateLastContentAdded"
}
```

### 3. 背景设计

- **纯色背景**: 使用颜色选择器
- **渐变背景**: 选择双色和方向
- **随机渐变**: 每次生成都随机颜色

## 🛠️ 常见问题

- **性能优化**: 如果图层过多导致卡顿，建议合并一些静态装饰元素。
- **字体支持**: 后端支持常见开源字体，如 Noto Sans。如果需要自定义字体，请参考开发文档。
- **修正模式**: 针对某些图案填充不齐的问题，可以在属性面板中微调偏移坐标。
