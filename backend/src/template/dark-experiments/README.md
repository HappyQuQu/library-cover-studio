# 七套深色试作模板

七套独立构图，使用可编辑的 Fabric 图层、媒体库标题变量和最多九张海报。与原有默认模板和上一批试作模板使用不同的 ID；不参与首次启动初始化或一键还原默认模板。

| 模板 | 构图 | 所需素材 |
| --- | --- | --- |
| 黑金展台 | 香槟金细框、三座高低展台、左侧大标题 | 3 张海报 |
| 午夜阶梯 | 五张海报沿阶梯上升、午夜蓝底色 | 5 张海报 |
| 赤焰快门 | 三幅斜向长条快门、暗红背景 | 3 张海报 |
| 全景夜航 | 影片背景宽银幕、上下黑边、左侧暗幕与大标题 | 首部影片的背景；缺失时使用海报 |
| 霓虹橱窗 | 左侧大图、右侧三幅小图、细青色光框 | 4 张海报 |
| 银幕折页 | 两幅画面组成折页、中央书脊阴影 | 2 张海报 |
| 碎片棱镜 | 九张菱形图片错落排列、左侧大标题 | 9 张海报 |

打开 [预览页](index.html) 比较风格，或查看 [Anime 真实素材总览](overview-Anime.jpg) 和 [TV 真实素材总览](overview-TV.jpg)。这些是通过项目渲染器生成的预览，未上传至 Jellyfin。

本机模板库使用「深色试作 · 」名称前缀，默认可编辑。配色固定，便于对比；可在设计器继续修改。图片不足时按现有自动化规则重复填充。

`packages/` 下每个 ZIP 是一套可以导入、分享的模板；`seven-dark-templates.zip` 是七套单独 ZIP 的合集，先解压再分别导入。

重新生成标准预览、源文件及导入包：

```sh
pnpm --filter ./backend exec node --import tsx ../scripts/create-dark-experimental-templates.mjs
```

如需同时生成真实素材预览，设置 `LCS_DARK_ARTWORK_DIR`，目录包含 `Anime/`、`TV/` 两个子目录，各包含 `post1.bin` 至 `post9.bin`、可选 `backdrop.bin`，以及记录标题和素材数量的 `info.json`。脚本只写预览文件，不修改数据库、初始化清单或媒体库封面。
