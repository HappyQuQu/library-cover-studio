# 七套实验模板

这批模板用于预览和继续设计，不参与首次启动初始化，也不属于「一键还原默认模板」的范围。现有七套默认模板保持原样。

打开 [预览页](index.html)，点击图片可看完整封面。也可以查看 [七套总览](overview.jpg)。

| 模板 | 构图 | 海报数量 |
| --- | --- | --- |
| 票根收藏 | 左侧单张海报，右侧票根标题、齿孔、编号与条码装饰 | 1 |
| 胶片放映 | 中部横向四格胶片，底部大标题 | 4 |
| 黑胶唱片 | 左侧圆形唱片与封面标签，右侧标题和两枚圆形图片 | 3 |
| 影像画册 | 上方标题，左下横向主图，右侧两幅小图及图注 | 3 |
| 轨道星图 | 五张圆形图片沿轨道分布，中央留白放标题 | 5 |
| 四幕蒙太奇 | 四角画面拼接，中央横贯标题带 | 4 |
| 蜂巢拼图 | 七张六边形图片组成蜂巢，底部主副标题 | 7 |

每套画布为 1920 × 1080，使用可编辑的 Fabric 图层、`{{primary_title}}` / `{{secondary_title}}` 标题变量，以及 `post1`～`post9` 海报变量。渲染时读取所选媒体库的真实海报。固定配色用于本轮评审，可在设计器中继续调整。

圆形和蜂巢海报的裁切随图片一起移动、缩放与旋转。当前版本的后端渲染器支持这些相对裁切；较早版本可能生成矩形图片，请先更新渲染器再用于自动化。

## 导入和分享

- `packages/` 中每个 ZIP 是一套可导入模板；在模板库点击「导入模板」选择单套 ZIP。
- `seven-experimental-templates.zip` 是七套 ZIP 的集合。先解压，再分别导入，不能把合集当作单套模板导入。
- 导入模板默认可编辑；可在模板库继续导出、复制或锁定。
- 本次在本机模板库安装的七套模板使用「试作 · 」名称前缀，不修改默认模板或现有自动化配置。

## 重新生成预览和导入包

在仓库根目录执行：

```sh
pnpm --filter ./backend exec node --import tsx ../scripts/create-experimental-templates.mjs
```

脚本只生成此目录的 JSON、预览、导入包和预览页，不写数据库或默认模板初始化清单。
